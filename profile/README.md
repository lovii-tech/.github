## Миссия

**Сначала задача района. Затем — сервис, который её решает.**

LOVII соединяет жителей, точки малого бизнеса, представителей, амбассадоров и инвесторов в одном контуре: точка получает цифровой канал без агрегаторов, житель — баллы, которые одинаково ценны у всех участников сети, партнёры — доход от растущей сети. Критерий успеха каждого модуля: стало ли участнику легче работать.

## Как устроена экономика

| Параметр | Значение |
|---|---|
| Нагрузка на точку | **не более 10%** от суммы заказа, включая эквайринг |
| Лояльность | **1 балл = 1 ₽** — единая валюта сети |
| Подключение | **бесплатное**, без платы за вход |
| Тарифы | СТАРТ 0% · БАЗОВЫЙ 10% · PRO 2 990 ₽/мес |
| Деньги | платформа **не хранит** средства клиентов: расчёты идут через банка-партнёра |
| Сплит сети | 40/40/20 — доли участников экосистемы |

Платформа не перепродаёт товары и не является платёжным агентом: приём средств — через партнёрский банк, фискализация — по правилам банка-эквайера.

## Роли в сети

| Роль | Что получает |
|---|---|
| **Житель** | Витрина района, кэшбэк баллами 1:1, единый кошелёк сети |
| **Точка МСП** | Цифровая витрина, программа лояльности, касса и чеки — без агрегаторов |
| **Представитель** | Сеть точек своего региона: подключение, сопровождение, доход с оборота |
| **Амбассадор** | Инструменты продвижения локальной сети и вознаграждение за рост |
| **Инвестор** | Участие в развитии сети на прозрачных правилах платформы |

## Принципы

- **Практическая польза.** Каждый модуль помогает в реальной работе участника сети.
- **Доступная экономика.** Бесплатное подключение, нагрузка на точку — не более 10%.
- **Прозрачные деньги.** Расчёты через банк-партнёра, сплит 40/40/20, никаких скрытых удержаний.
- **Локальная сеть важнее агрегатора.** Доход остаётся в районе, а не у посредника.
